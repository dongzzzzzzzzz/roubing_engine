## 4. 特殊概念应怎样写入手册

建议直接在 Stage 11 后追加“特殊概念操作边界”章节。不要把这些词另做一套选股系统，它们只能修正前面 Stage 1—11 的判断。

### 4.1 反人性

稳定含义不是“别人恐慌就抄底”，而是：在市场共识或情绪偏向一侧时，已有节点、角色和价格行为给出了相反且可验证的证据。

必须依次具备：

1. 可观察的恐慌、一致性或旧预期；
2. Stage 3 已存在合法节点；
3. 股票在真实竞争组中完成稀缺角色或唯一性任务；
4. 竞价或开盘触发得到确认。

缺少节点或确认时，只能写“逆共识候选”，不能写反人性买点。系统性下跌未止、板块和核心一起弱时，禁止用“别人恐慌”合理化抄底。

### 4.2 分歧

必须明确对象、范围和时间窗口：市场分歧、板块分歧、角色组分歧或单股分歧不能混写。

可观察事实包括：涨跌分化、涨停成功率下降、炸板增加、前后排分化、核心与容量不同步、价格大幅往返、成交放大但方向未决。

分歧本身不是好坏结论。只有后续修复、承接和买方反馈才能区分良性换手与结构破坏。

### 4.3 共振

不能因为一只股票上涨就写板块共振。至少列出两个独立层级在同一时间窗口同向变化，例如：指数/环境、方向宽度、情绪核心、容量核心、助攻梯队。

必须保存各对象事件时间。同步只证明共同发生，不自动证明因果。只有单股脉冲或后排未响应时，降级为单票行为。

### 4.4 分离和强弱切换

必须先定义可比较的对手、原排序和共同任务，再记录事件顺序：谁先弱、谁逆势走强、谁次日继续完成任务。单个一分钟脉冲不能确认分离。

强弱切换不是“旧股跌、新股涨”这么简单；新股还要接过旧股原先承担的外部功能，例如稳住板块重心、打开空间或带动后排。

### 4.5 上升停顿

这里有明显双重口径：

- 2026-03-14 把上涨后的停顿及关键位该涨不涨用于退出；
- 2026-05-04 又明确说停顿不等于趋势终结，也可能是控速、换手和二次蓄力。

因此统一状态只能是 `PAUSE_PENDING_DIRECTION`。下一步看：向下破关键支撑且反抽无力，则确认负向；重新放量突破、角色和板块响应，则确认空中加油或二次启动。不得看到停顿就自动买，也不得自动卖。

### 4.6 巨量

作者没有统一倍率。必须同时比较：

1. 相对自身近期量能；
2. 换手和流通规模；
3. 所处低位还是高位；
4. 巨量后的价格结果；
5. 次日是否继续得到买方反馈。

低位巨量不自动等于吸筹，高位巨量不自动等于出货。量能只能形成候选解释，必须由价格和后续反馈确认。

### 4.7 洗盘和出货

不能推断“主力意图”，应改写成可观察状态。

洗盘候选：原趋势和关键支撑仍在；调整缩量或反复上影但没有有效破位；突破后回踩能重新站回；板块弱时个股停止继续下跌。之后仍须等重新突破或弱转强确认。

出货候选：高位或加速后，竞价低于逐票预期且不能快速修复；放量滞涨；同批助攻持续大跌；日内高点形成后长期不能夺回；次日继续不给买方奖励。

二者都必须写“候选”，直到后续行为确认；不得把图形直接解释成主力行为。

### 4.8 超买、超卖、背离、等距浪

这些只能做风险或修复候选，不能独立生成节点。作者没有给出统一 RSI/MACD 参数、时间尺度或等距算法。

工程可以保存明确版本的指标特征，但必须标记为模型特征，不得冒充 roubing 的稳定规则。2026-07-18 的第一波/第三波等距属于单篇案例 `[K]`。

### 4.9 效应复制

复制的是完整关系，不是股票名字或 K 线外形。必须记录：前一个已验证案例的环境、节点、角色、竞争方式、触发和失效条件；新候选只有在这些关系仍存在且前一效应仍给买方正反馈时，才是复制候选。

作者没有说明效应何时耗尽，也没有同期失败对照组。因此必须同时保存匹配但失败的候选，不能只记录成功案例。

### 4.10 冰剑

它是动作层包装，不是新的选股源：

- “冰”：合法路径内，经过支撑、回踩、企稳和拐头确认的低吸防守；
- “剑”：合法路径内，经过超预期、突破、放量和主动推进确认的进攻；
- 退出：预期失败、上升停顿向下确认或角色被替代后处理。

候选仍必须先通过 Stage 1—7，不能因为出现“冰”或“剑”的形态绕过环境、节点、角色和竞争组。

### 4.11 瓶底

瓶底只能生成中周期方向假设，不能直接生成买点。应分开核验：产业周期、政策、估值、资金供需、高低切换和筹码结构。作者没有给出这些因素的固定权重。

公司和产业事实必须来自正式公告、财务数据、政策原文和产业资料，不能使用作者帖子作为事实。仅仅“冷门、低位、跌得多”不能判定瓶底。方向假设还要回到 Stage 2—10，经过资金、容量、角色、节点和触发确认。

### 4.12 低熵秩序

这是结构比喻，不是数学熵公式。可观察组成是：

- 主方向连续；
- 总龙/情绪核心承担空间功能；
- 容量或中军稳住板块重心；
- 助攻和低位扩散赚钱效应；
- 分歧后能修复；
- 次日买方持续得到奖励；
- 角色和节奏可预期。

若方向每天轮换、角色频繁替换、只有孤立脉冲、核心高位滞涨、中军和跟风同时掉队，则是高熵或无序状态。不要发明一个未经验证的“熵分数”。
