## 1. 我们真正要做的事

不是把 roubing 的文章改写成术语表，也不是照搬“龙头、主流、弱转强、唯一性”这些词，而是回答：

1. 当天收盘时，市场处于什么阶段，哪条方向正在获得资金注意力？
2. 这条方向是临时热点、弱主流、普通主流，还是经过多次压力测试的超级主流？
3. 方向内部谁在承担情绪、定价、容量、扩散和接收资金的不同角色？
4. 明天资金最可能沿哪条路径继续赚钱？什么事实会让这条路径失效？
5. 交易时买哪个角色、等什么确认、买多少、什么时候退出？
6. 交易结束后，实际发生的结果是否支持原来的判断，还是只是个股偶然上涨？

最终要形成的工作顺序是：

```text
市场周期
-> 主流方向
-> 节点类型
-> 方向内部角色
-> 竞争与唯一性
-> T 日盘后路径
-> T+1 竞价和开盘验证
-> 分时买点
-> 仓位
-> 持有、切换或退出
-> 结果复盘和规则修正
```

这个顺序比“先找当天涨得最多的股票，再给它编一个故事”更接近 roubing 文章中反复出现的真实思考过程。

## 2. 研究纪律

### 2.1 必须把文章放回当时的日期

每篇文章不能只写作者的结论。必须拆出：

- 原文每个关键句到底在解决什么交易问题。
- 例子发生前，交易者当时已经知道什么。
- 例子当天指数、板块、核心、容量、助攻和失败股分别发生了什么。
- 作者提到的竞价、开盘、承接、回封，哪些有独立数据支持，哪些只能标为作者盘中记录。
- 同一天还有哪些合理竞争者，为什么最后不是它们。
- 结果出来后，哪些判断被支持、部分支持或证伪。
- 这篇文章给框架增加了什么边界，而不是只增加一句口号。

### 2.2 严格区分事实、推断和后验

- `事实`：来自历史日线、公告、交易所规则、可靠新闻或可复核的盘口数据。
- `作者记录`：文章中作者声称盘中发生的事情，若没有第二来源，必须保留这个标签。
- `我们的推断`：根据事实对资金路径作出的解释。
- `后验结果`：T+1、T+2 之后才知道的结果，不能倒推成 T 日已经确定的事实。

缺少 9:15-9:25、分钟或逐笔数据时，不能编造封单、撤单、分时拐点、回封顺序和承接强弱。统一写成 `待盘口核验`。

### 2.3 不设置脱离语境的固定公式

目前不把“连续几天、涨幅多少、成交额多少、竞价高开多少”直接当成万能门槛。它们只能在具体周期、角色和竞争关系中解释。后续如果要固化阈值，必须经过多个成功样本和失败样本的共同验证。

## 4. 从 roubing 文章中提炼出的总框架

本节是框架总览；真正执行时以 [TRADING_FRAMEWORK_OPERATIONAL_SPEC_V0_1.md](/Users/lee.dong/Documents/ChatGPT/test-stock-1/roubing_research_2026/TRADING_FRAMEWORK_OPERATIONAL_SPEC_V0_1.md) 的字段和判定步骤为准。总纲里的“市场环境、周期、主流、节点、角色、唯一性、竞价、买点、仓位、卖点”都已经在该文件中展开，不能只读本节的概念标题。

## 4.1 第一层：先判断市场环境和周期位置

交易不是每天都有机会。先判断市场整体是在：

- 主流形成：新方向刚开始获得资金验证。
- 主流主升：核心、容量、梯队和买方回报形成正循环。
- 主流第一次分歧：已经确认的方向第一次受到群体卖压，可能修复或结束。
- 主流高位震荡：已经多次分歧，资金在核心之间轮动，不能再套用第一次分歧的预期。
- 退潮和切换：旧主流无法继续给买方利润，新方向或新载体争夺注意力。

每天先看：

```text
昨日强势股今天是否有溢价？
今天买入者是否有赚钱机会？
亏钱效应是在个别股票，还是已经扩散到一个方向？
指数是在降低阻力，还是迫使资金抱团？
```

不能因为一只股票涨停，就把市场定义为可做；也不能因为指数弱，就认为所有强股都没有机会。要区分“市场整体阻力”和“局部抱团”。

## 4.2 第二层：判断哪条方向是主流

主流不是当天涨停数量最多的板块，而是市场资金持续选择、能让不同位置买入者获得回报的方向。

至少检查四件事：

1. **连续性**：不是单日消息脉冲，方向在多个交易日保持关注和资金承接。
2. **角色完整**：至少同时存在情绪或高度载体、换手核心、容量或趋势承接，以及一定的扩散层。
3. **正反馈**：前一批买入者没有被批量闷杀，后续资金仍愿意接力。
4. **市场注意力**：方向的强弱会影响全市场复盘，其他股票会围绕它做选择。

主流分级：

| 级别 | 识别 | 交易含义 |
| --- | --- | --- |
| 随机热点 | 单票或单日脉冲，没有角色和延续 | 不做 |
| 弱主流 | 有试盘、先锋或容量反包，但持续性尚未充分证明 | 小仓，只做最强确认 |
| 普通主流 | 核心、容量、梯队和买方回报已被验证 | 可以做节点和第一次分歧 |
| 超级主流 | 经历多次独立压力测试，每次都有新承接和下一棒 | 可以围绕核心反复做，但仍需看位置和监管 |

“超级主流”不是机械完成四次修复，而是每次出现真实卖压后，市场都重新选择这个方向，并出现多角色接力和后续奖励。

## 4.3 第三层：判断今天是什么节点

节点不是日期标签，而是资金阻力发生变化的位置。已经提炼出的节点类型：

| 节点 | 实际含义 | 应观察的事实 |
| --- | --- | --- |
| 共振节点 | 指数、板块和个股同向，买方阻力降低 | 指数止跌或突破，板块扩大，核心带动 |
| 稀缺性节点 | 市场在多个竞争者中形成唯一选择 | 唯一高度、唯一换手、唯一容量或唯一纯度 |
| 反转节点 | 原本应该弱，却出现逆预期承接 | 大阴、平台或炸板后的真实反包 |
| 反身节点 | 低位候选经过连续竞争，开始自我强化 | 第一天出现，后续持续，竞争后留下唯一者 |
| 分离节点 | 旧路径走弱，新载体不跟跌并开始承接 | 旧核心负反馈与新载体主动性同时出现 |
| 高低切节点 | 高位核心停顿，资金寻找新的接收层 | 总龙断板或二波分歧时，低位直接相关股票主动接力 |
| 情绪转折节点 | 退潮后出现第一只改变情绪的载体 | 水下拉红、弱转强、突破高度并带动情绪 |

节点有效性的核心检验不是“股票涨了”，而是“在这个节点买入的人，是否获得了继续赚钱的路径”。

## 4.4 第四层：给方向内部股票分角色

A/B/C/D 是我们的工程标签，不是 roubing 的原词：

| 层级 | 角色 | 负责回答的问题 |
| --- | --- | --- |
| A | 情绪核心、周期总龙、主流唯一核心 | 谁拥有当前方向的定价权和市场辨识度？ |
| B | 容量核心、中军、趋势核心 | 大资金能否参与，方向是否有承接重量？ |
| C | 伴飞龙、分支前排、同题材扩散 | 赚钱效应能否从核心扩散出去？ |
| D | 补涨、低位伴生、资金接收层 | 高位停顿后，新的资金接收在哪里？ |
| 失败层 | 昨强今弱、炸板、冲高回落、破位票 | 卖压是否正在扩散？ |

角色不是股票的终身称号。C 可以在竞争中升级为新的 A，原 A 也可能因为失去带动性降级。D 的“低位”是相对代际位置，不是股价绝对低。

低位股不能因为跌得少就自动成为 D。必须证明它与原主流有直接资金关系，并且是在高位停顿、断板或切换节点接住了资金。

## 4.5 第五层：唯一性来自竞争，不来自主观偏好

每天要把合理竞争者放到同一张表中比较：

- 从方向启动日算，谁的区间表现最强？
- 谁是唯一高度，谁是唯一换手，谁是唯一容量，谁是唯一纯题材？
- 谁在同一轮卖压中更抗跌？
- 谁在修复时最先获得主动买盘？
- 谁的上涨能带动其他角色，而不是孤立上涨？
- 哪个竞争者一旦强于它，原来的唯一性就消失？

南京公用与国旅联合的相反结果说明：同题材、同节点、同为低位首板并不等于同质量。还要比较前期累计涨幅、筹码压力、剩余空间、此前身份和次日主动性。

三祥新材与瑞泰新材的相反结果说明：同日修复涨停也不等于隔夜价值相同。主板高度与市场锚点、20CM 弹性表达、当日预期消耗和下一棒空间必须分开判断。

## 4.6 第六层：盘后推演资金下一步去哪里

盘后不是预测唯一答案，而是列出有条件的路径：

```text
路径一：原核心修复
成立条件：原核心达到应有开法，容量或先锋同步，卖压被吸收。
失败条件：原核心不及预期，容量继续弱，后排批量亏钱。

路径二：新核心接管
成立条件：新载体在同一卖压中更抗跌，次日主动转强并带动方向。
失败条件：只有新载体孤立上涨，旧路径和容量继续崩溃。

路径三：方向结束，资金离开
成立条件：核心、容量和扩散层共同失去承接，买入者得不到回报。
```

每只候选都要写“应有开法”：如果昨天下跌是正常获利兑现，明天应该怎样开；怎样开只是普通反抽；怎样开代表继续退潮；需要谁同步；哪个竞争者更强就放弃它。

## 4.7 第七层：竞价和开盘只验证已有路径

竞价不是重新编故事，而是检查盘后推演是否被市场接受。

观察顺序：

1. 9:15 初始预期：核心、容量、低位接收和失败组分别怎么开。
2. 9:20 撤单后的真实变化：表面强度是否消失，卖盘是否继续增加。
3. 9:25 最终撮合：是否有真实成交和多角色同步。
4. 9:30-9:35 开盘验证：第一轮兑现是否被吸收，价格是否重新主动，板块是否响应。

四种处理：

| 反馈 | 处理 |
| --- | --- |
| 预期被改写，核心与另一角色同步 | 进入开盘确认 |
| 只有单核心高开，容量和后排不跟 | 继续观察，不定义为方向修复 |
| 原核心弱，新载体更主动且能带动方向 | 转向新核心验证 |
| 核心、容量和接收层都低于应有开法 | 取消路径，不找理由硬做 |

竞价强不等于可买。高开过多、一字无法成交、只有封单没有换手，都可能意味着强度已经透支或无法验证承接。

## 4.8 第八层：买点是承接后的主动，不是看到涨就追

当前主要买点有三种：

### A. 原核心弱转强

- 分歧前已拥有定价权。
- 确实是第一次大分歧，且没有明显顶部背离。
- 次日竞价改写了继续下跌的预期。
- 开盘第一轮卖压被吸收，价格重新主动。
- 至少一个容量、先锋或直接相关角色同步。

### B. 容量核心放量修复

- 方向仍有情绪或先锋维持注意力。
- 容量在分歧日没有结构破坏。
- 次日真实成交吸收卖盘并重新走强。
- 容量转强能够带动板块，而不是板块被动抬升它。

### C. 分歧中胜出的新核心

- 原核心低于应有表现。
- 新载体在同一卖压中更抗跌。
- 次日主动转强并带动同方向股票。
- 这是资金在原主流内部迁移，不是资金已经离开后的小票孤涨。

买入前必须回答：买的是哪个角色、昨晚哪条路径、谁会接棒、如果没有同步响应在哪里放弃。

## 4.9 第九层：仓位由阻力决定

当前只使用仓位单位，不先强行规定账户百分比：

| 证据状态 | 动作 |
| --- | --- |
| 无主流、无节点、亏钱效应扩散 | 空仓 |
| 有候选但只得到竞价支持 | 不买或观察 |
| 核心承接成立，板块响应一般 | 试错单位 |
| 核心/容量与另一角色共同修复 | 标准单位 |
| 多次压力测试后仍有主流合力，次日继续奖励 | 才讨论增加 |

弱势环境轻仓，不因为主观确信而加仓；超级主流也不是任何位置都能重仓。仓位要反映市场阻力、可验证程度和失败后的退出成本。

## 4.10 第十层：卖的是秩序松动，不是单纯价格涨跌

需要重点观察：

- 核心放量冲高不封、涨停反复，定价权减弱。
- 容量低开低走或反包失败，大资金承接消失。
- C/D 层批量冲高回落、没有溢价，扩散赚钱效应消失。
- 竞价应强不强，昨晚路径被证伪。
- 异动或监管约束提高，下一棒资金接不动。
- 修复日买入者次日没有得到回报。
- 同方向新载体已经接管带动性，原核心变成被动跟随。

处理逻辑：出现一个信号先降级观察，两个信号降仓，三个信号或核心地位被取代则退出。这个是风险组织原则，不是机械打分器。

## 4.11 异动和监管是约束条件

异动不是简单的买点，也不是看到就机械卖出。要结合主流级别、核心地位、接棒能力和监管公告判断。

- 超级主流中，异动后仍有承接，可能只是限制载体，不一定限制方向。
- 普通主流中，异动提高次日不确定性，应降仓等待确认。
- 弱主流或随机热点中，异动更容易变成兑现点。
- 连板受到约束但方向仍强时，资金可能转向趋势容量或低位接收层。

涉及 10 日、30 日严重异常波动时，必须按交易所正式的涨跌幅偏离值口径计算，不能拿裸涨幅代替。

## 5. 当前最清晰的专项模型：主流第一次分歧修复

这个模型的边界必须守住：

- 分歧前方向已经确认是主流。
- 这是主流确认后的第一次真正群体卖压。
- 核心、容量或至少一个关键角色没有结构性破坏。
- 次日要经历“预期改写、卖盘吸收、多个角色同步”三层验证。

不属于本模型的情况：

- 新题材启动后的第一次反包，那是主流形成确认。
- 已经多次分歧后的高位轮动。
- 平台突破烂板后的新阶段弱转强。
- 总龙断板后的普通补涨。
- 单只股票脱离板块的独立反包。

完整修复不是“一只股票涨停”，而是：

```text
方向前期已形成主流身份
-> 第一次群体卖压出现
-> 结构仍可修复
-> 次日预期没有继续恶化
-> 第一轮卖盘被吸收
-> 核心、容量、低位或助攻至少两个独立角色同步
-> 新买方获得正反馈
```

如果只有一只股票修复、容量和其他前排继续弱，只能叫单股修复；如果买入者当天和次日都得不到回报，模型失败。

已核对的典型边界：

- 2023-02-08/09 人工智能：方向修复成立，但慧博云通次日延续失败，说明修复成立不保证隔夜继续上涨。
- 2024-04-08/09 固态电池：三祥新材与瑞泰新材同日修复，但次日表现分化，说明角色和下一棒空间比日内涨幅重要。
- 2024-06-17/18 车路云：更接近主流形成确认，不应误归入第一次分歧修复。
- 2024-11-14/15 有研新材：主要是单股人气修复，不能代表方向整体修复。
- 2025-11-27/28 商业航天：情绪、趋势、低位、材料和容量多角色共同修复，是目前最完整的正样本。

## 10. 当前结论

我们目前已经有一套相对完整的“思考骨架”，但还不是经过全量样本验证的最终交易系统。

已经比较明确的主干是：

```text
先看周期和市场阻力
-> 再认定主流方向
-> 再识别节点
-> 再给股票分角色
-> 在竞争中找唯一性
-> 盘后推演资金下一步路径
-> 用竞价和开盘验证
-> 只买承接后的主动
-> 按阻力控制仓位
-> 按秩序松动退出
```

最重要的认识不是“某种形态必涨”，而是：

> 交易机会来自资金阻力下降和买方能够继续获得回报；交易风险来自原有秩序失效、卖压扩散和下一棒消失。
